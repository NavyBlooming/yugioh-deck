# Proposal

## Why

名前を知らないカードを、「闇属性のドラゴン族」「攻撃力2500以上」のような条件で探したい。カードデータに属性・種族・攻守が入ったので、それで絞れるようにする。

## What Changes

- 検索欄の横に「絞り込み」を足し、カードの種類・魔法罠の種類・属性・種族・チューナーなど・レベル／ランク／リンク・攻撃力・守備力で絞れるようにする
- 同じ項目の中は「どれか」、項目どうしは「すべて」。名前が空でも絞り込みだけで並べ、名前を入れればその中から絞る
- 絞り込み中は検索欄の下に条件を出し、× で解除する。条件はデッキを開いている間だけ覚える
- 種族などが増えたとき: 名前の表に無い種族は「その他の種族」と出し、絞り込みの「その他」で探せる。毎週の更新は、名前の表に無い番号を meta.json に書き、実行結果に警告を出す
