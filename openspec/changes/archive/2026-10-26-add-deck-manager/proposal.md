# Proposal

## Why

紙の遊戯王OCGで複数のデッキを組んでいると、デッキごとに「どのカードが手元に無いか」「あと何を何枚買えばよいか」を把握しづらい。公式の遊戯王ニューロンや公式カードデータベースではデッキは作れても、未所持のカードと買い物の管理はできない。カードショップの店頭でスマホから確かめられる、マスターデュエルのデッキ編集に近い操作感の管理ページを用意する。

## What Changes

- 全OCGカードの日本語名・読み仮名・カードの種類・禁止制限の状態を持つカードデータを用意し、週1回自動で更新する
- カード名または読み仮名でカードを探せるようにする（ひらがな・カタカナ・全角・半角の違いは無視）
- デッキをメイン・エクストラ・候補の3区分で組めるようにし、公式ルールに沿った上限と警告を出す
- デッキ内のカードを1枚ずつ「未所持」にでき、未所持のカードを暗く表示する
- デッキごとの買い物リスト（単価・合計金額・欲しいレアリティと収録パック・カードラッシュへのリンク）を出し、「買った」で未所持を解消できるようにする
- カードのイラストを暗号化して公開リポジトリに置き、合言葉を入れた人にだけ表示する
- 利用者のデータを端末内に保存し、JSONファイルで書き出し・読み込みできるようにする

## Capabilities

### New Capabilities

- `card-catalog`: 全OCGカードの名前・読み仮名・種類・禁止制限の状態の提供と、その定期更新
- `card-search`: カード名と読み仮名による検索
- `deck-library`: デッキの作成・名前の変更・削除と、デッキ一覧での状況表示
- `deck-building`: デッキの区分ごとのカードの出し入れ、枚数の上限、並び順、ルール違反の警告
- `card-ownership`: デッキ内のカード1枚ごとの未所持の記録と表示
- `shopping-list`: 未所持カードの買い物リスト、価格と購入メモ、購入の記録
- `card-artwork`: 暗号化したカードイラストの配布と、合言葉による表示
- `data-portability`: 利用者データの端末内保存と、書き出し・読み込み

### Modified Capabilities

（なし）

## Impact

- 新規リポジトリ `NavyBlooming/yugioh-deck`（GitHub Pages で公開）
- 外部データへの依存: ygocdb の一括データ（カード名・読み仮名・種類）、YGOPRODeck（禁止制限の状態・切り抜きイラスト）、YGOResources（日本版の収録パック、画面から1枚ずつ取得）
- GitHub Actions の定期実行と、合言葉を入れる Secrets
- カードイラストの著作権は KONAMI にあり、公開リポジトリには暗号化した状態でのみ置く
