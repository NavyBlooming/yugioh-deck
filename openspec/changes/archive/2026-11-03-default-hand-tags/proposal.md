# Proposal

## Why

誘発のカードは、どのデッキでもほぼ必ず誘発の印を付ける。デッキに入れるたびに手で付けるのは手間なので、決まったカードには最初から付ける。

## What Changes

- 決まった28枚（幽鬼うさぎ、灰流うらら、増殖するG、無限泡影、霊王の波動、聖王女ローズパメラなど）は、デッキに初めて入れたときに誘発の印を付ける
- 一度外した印は、そのデッキにカードが残っている間は付け直さない
