# yugioh-deck

紙の遊戯王OCGのデッキと、デッキごとに手元に無いカード（買いたいカード）を管理するページです。スマホで開くことを想定しています。

公開ページ: <https://navyblooming.github.io/yugioh-deck/>

## 使い方

- **デッキを作る**: 「デッキ」タブの「＋ 新しいデッキ」。
- **カードを入れる**: デッキを開き、下の検索欄にカード名か読み（ひらがな・カタカナどちらでも）を入れて、結果のカードをタップ。
  - 合言葉を入れていれば、効果テキストでも探す。名前で当たるカードの後ろに、スペースで区切った語をすべて含むカードが並ぶ。
  - 「追加先」を「候補」にすると候補カード欄（15枚まで）に入る。
  - 同じカードはメイン・EX・候補の合計で3枚まで。メインは60枚、EXは15枚まで。
- **履歴・お気に入り**: 検索欄の上の「履歴」タブに、そのデッキで最近入れたり抜いたりしたカード（新しい順に30件まで）が、「お気に入り」タブに全デッキ共通のお気に入りが出る。タップすると追加先に入る。お気に入りへの追加と解除は、カードの長押しのメニューから。
- **発売前のカード**: 発売予定の商品のカードは、毎週の更新で自動的に検索に出る。載っていないカードは、「設定」の「発売前のカード」で、カード名・読み・種類を入れて登録すると、検索してデッキに入れられる。発売されてカードデータに同じ名前のカードが入ったら、開いたときにそのカードに置き換わる。
- **手元に無いカードの印**: デッキ内のカードをタップすると、その1枚が暗くなる（もう一度タップで戻る）。
- **カードの操作**: カードを長押しすると、抜く・候補との移動・表紙にする・購入メモ・公式DB・カードラッシュのメニューが出る。
- **買い物リスト**: 「買い物」タブに、デッキごとの未所持カードと合計金額が出る。店で買ったら「買った」を押すと、デッキ側の暗い表示も1枚減る。
- **端末の移行・バックアップ**: 「設定」タブの「書き出し」でファイルに保存し、別の端末の「読み込み」で戻す。データはそれぞれの端末のブラウザに保存されている。

## ログインと同期

「設定」タブの「Google でログイン」で、同じ Google アカウントのスマホと PC のデッキと購入メモを同じにできます。ログインしなくても、端末の中だけで今までどおり使えます。

- 変更はすぐ端末に保存し、クラウド（Firebase の Cloud Firestore）には30秒に1回まで、ほかのアプリやタブに切り替えたときにも保存します。
- 別の端末の変更は、ページを開いたときと、ほかのアプリやタブから戻ったときに取り込みます。開いたまま見ている画面には出ません。
- 初めてログインしたとき、端末とクラウドの両方に違うデータがあれば、どちらを使うかを選びます。選ばなかった方は置き換えられます。
- 両方の端末で同時に編集すると、後から保存した方が残ります。
- 電波が無いときの変更は端末に残り、電波が戻ったときか次に開いたときに保存します。
- カードの絵の合言葉はクラウドに送りません。端末ごとに入れてください。
- ログアウトしても、端末のデータはそのまま残ります。

クラウドのデータは本人だけが読み書きできます（`firestore.rules`）。

## カードの絵

カードの絵と効果テキストは暗号化して置いてあり、合言葉を知っている人にだけ表示されます。合言葉は「設定」タブの「カードの絵」に入れてください。合言葉が無くても、絵の代わりに枠の色とカード名で表示され、ほかの機能はすべて使えます。

合言葉を変えるときは、`.env` の `YGO_ART_PASSPHRASE` と GitHub の Secrets を新しい値にし、`art/` を消してから `uv run tools/build_art.py` と `uv run tools/build_texts.py` で作り直します。

## データの出典

| データ | 取得元 | 使い方 |
| --- | --- | --- |
| カード名・読み仮名・カードの種類 | [ygocdb](https://ygocdb.com/api) の `cards.zip` | 全カードを1回で取得。`cards.zip.md5` で更新の有無を判定 |
| 禁止・制限・準制限 | [公式カードデータベースのリミットレギュレーション](https://www.db.yugioh-card.com/yugiohdb/forbidden_limited.action) | 一覧に無いカードは無制限 |
| 種類の補完 | [YGOPRODeck](https://ygoprodeck.com/api-guide/) の `cardinfo.php?misc=yes` | ygocdb に種類が無いカードだけ。`misc_info[0].konami_id` を公式のカードIDとして結び付ける |
| 効果テキスト | [mycard/ygopro-database](https://github.com/mycard/ygopro-database) の `locales/ja-JP/cards.cdb` | パスワードから ygocdb の対応で公式のカードIDに結び付け、合言葉で暗号化して `art/texts.bin` に置く |
| 発売前のカード | [遊戯王カードWiki](https://yugioh-wiki.net/) のカードリストにある発売予定の商品のページ | カードデータに無い収録カードのページから、カード名・読み・種類・レベル・魔法罠の種類だけを取り、`data/prerelease.json` に置く。効果テキストは取らない。ページの間は2秒空ける |
| 日本版の収録パック（型番） | [YGOResources](https://db.ygoresources.com/about/api) の `/data/card/<cid>` | 購入メモを開いたときに、そのカードの分だけ画面から取得 |

日本語名の無いカードと、どの取得元にも種類の情報が無いカードは除き、`data/meta.json` の `excluded` に載せています。

## カードデータの更新

```sh
uv run tools/build_cards.py
```

カードの元データも禁止制限の一覧も前回から変わっていなければ `unchanged` と出て、何も書き換えません。

GitHub Actions が毎週月曜3時（日本時間）に、カードデータの更新と、新しいカードの絵の追加、効果テキストと発売前のカードの更新を行います。「Actions」タブから手動でも動かせます。

## テスト

```sh
npm test
uv run pytest
```

アクセス規則の試験は、Firebase のエミュレーター（JDK 11 以上が要る）を起動してから動かします。

```sh
npx firebase-tools emulators:start --only auth,firestore --project demo-yugioh-deck
npm run test:emulator
```

画面を `index.html?emulator=1` で開くと、本物の Firebase ではなくエミュレーターにつなぎます。
